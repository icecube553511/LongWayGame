## 1. 我自己的扫描脚本（与问题稿的 PowerShell 版不同实现）

```powershell
node -e "const fs=require('fs'),p=require('path');
const files=fs.readdirSync('art').filter(f=>/^scenes.*\.js$/.test(f)).sort();
const map=new Map(); let dup=0;
for(const f of files){
  fs.readFileSync(p.join('art',f),'utf8').split(/\r?\n/).forEach((l,i)=>{
    const m=l.match(/ART\.scenes\s*\[\s*'([^']+)'\s*\]\s*=\s*function/);
    if(!m) return;
    if(map.has(m[1])){ dup++; console.log('重复: '+m[1]+'  '+map.get(m[1])+'  |  '+f+':'+(i+1)); }
    else map.set(m[1], f+':'+(i+1));
  });
}
console.log('注册总数(去重后)='+map.size+'  重复='+dup+'  扫描文件='+files.join(','));"
```

输出（原文）：

```
注册总数(去重后)=30  重复=0  扫描文件=scenes.js,scenes_jiang.js,scenes_meeting.js,scenes_north.js,scenes_river.js
```

即：5 个 `scenes*.js` 现在一共注册 **30 个唯一背景 id，重复 0**，
而 SPEC §4.1 的背景表正好是 30 个 —— 数量对得上，没有 id 在删除过程中丢失。
