## 改动

选了原稿给的**第二条路**（补一个 `cg` 步），而不是从 `CG_LABEL` 里删掉这一格。

理由：`assets/generated/cg/bg_xiangjiang_day.svg` 已经烘焙好了（实测 **596,662 字节 / 583 KB**，
比同 id 的背景 `bg/bg_xiangjiang_day.svg` 的 595,143 字节多 1,519 字节——按 ART_DIRECTION
§3 的约定它是同 id 背景的"加强版"，不是冗余文件），`README.md` §四也承诺「每章都至少有一处全屏插画」+
「插画画廊里列了 20 张可解锁的」；删掉标签会让玩家少一张本该拿到的插画，还要连带改
README。补步则与 SPEC §2.1 的 `cg`（`id` + `text?`）完全对齐，不新增任何 step 类型。

`src/story/ch03.js`（INDEX §3 只授权 g2_eng 在 Q09 所需范围内动这个文件），在开篇旁白
收束、切进「光华铺」之前插入一行：

```js
      { t: 'narr', text: '而这四天，要有人在渡口上守着。' },
      { t: 'cg', id: 'bg_xiangjiang_day', text: '十一月二十七日，白昼。江面上架起了浮桥。' },
      { t: 'title', text: '十一月二十七日 · 光华铺', sub: '红三军团' },
```

选这个位置的三个理由：① 这一拍本来就是"渡江前的白昼江面"（该章首个 `bg` 就是
`bg_xiangjiang_day`），图注与前后旁白同一时间线；② `浮桥` 是本章既有意象
（`ch03.js:25` 「把那条浮桥再检查一遍」），不是新造的设定；③ 章内已有 2 个 `title` 卡
与 1 个 `cg`，此处是唯一一处"叙事换场"，3200ms 的阻塞停顿放在这里不打断任何对白。

没有改 `src/engine/gallery.js`：`CG_LABEL` 保持 20 项，与 README §四 的承诺一致。
