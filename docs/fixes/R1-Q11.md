## 改动

`tools/validate-svg.js`（本轮 `tools/` 独占给 g2_eng）：三个**字面量子串**检查
（`NaN` / `undefined` / 空 `fill=""`）与"文件以 `<svg` 开头"检查，从"整份源码"改成
"剔除内嵌 data URI 之后的内容"，并把标签扫描也切到同一份内容上，保证下标口径一致。

```js
  /* 先去掉 XML 声明与注释，避免误判 */
  const clean = src.replace(/<\?[\s\S]*?\?>/g, '').replace(/<!--[\s\S]*?-->/g, '');
  /* 再剔除内嵌 data URI：命中 base64 载荷的子串不是故障（见文件头说明） */
  const bare = clean.replace(/data:[A-Za-z0-9.+-]+\/[A-Za-z0-9.+-]+;base64,[A-Za-z0-9+/=]+/g, '«B64»');
  if (bare.trim().indexOf('<svg') !== 0) problems.push('文件不以 <svg 开头');
  if (bare.indexOf('NaN') >= 0) problems.push('含 NaN 数值');
  if (bare.indexOf('undefined') >= 0) problems.push('含 undefined');
  if (/\bfill=""/.test(bare)) problems.push('含空 fill=""');
```

相对改动：**新增** `bare` 那一行（`const bare = clean.replace(...)`，位于
`tools/validate-svg.js:43`）；下面 4 个 `if` 原本依次读 `clean.trim()` / `src` / `src` /
`src`，现在统一读 `bare`。标签扫描原本读 `clean`，现在读 `bare`：

```js
  while ((m = tagRe.exec(bare)) !== null) {      // 原为 tagRe.exec(clean)
  const ltCount = (bare.match(/</g) || []).length;   // 原为 clean.match
```

并在文件头补了一段说明，写清"为什么必须先剔除 data URI"（18 张背景内嵌群众贴图，
base64 的随机三个字母会凑出 `NaN`），免得后来者把这段代码当多余的防御删掉。
