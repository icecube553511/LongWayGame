## 1. 问题（复述）

`docs/SPEC.md` §7 要求「每章正文对白 ≥ 3000 个汉字（含旁白）」，而 `R1-Q05` 把 27 个
**玩家永远看不到的沉默 note 步**改成对白上的 `note:` 字段之后，`tools/check.js` 的
`hanzi()`（只统计 `say`/`think`/`narr`/`note` 步的 `text`）立刻显出真实欠账：
ch05 / ch06 / ch08 / ch13 / ch15 / ch19 六章低于 3000。

这不是"计数口径变了"，而是这六章本身**内容偏薄**（改前它们也是全书最薄的六章）。
因此本条按 `R2-INDEX.md` §8 的边界办：**补内容，不改口径** ——
`docs/SPEC.md`、`tools/check.js` 一律未动，`note:` 字段也没有被算进正文。
