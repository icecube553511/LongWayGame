## 改动

只动一处：`src/engine/engine.js` 的 `boot()`，在动态注入之前先判断这一章是否**已经注册**。

```diff
     var m = manifestList();
     var missing = [];
     for (var i = 0; i < m.length; i++) {
+      /* index.html 已经静态加载过全部章节；已经注册过的不要再注入一次，
+         否则每个章节 IIFE 会被解析并执行两遍（20 章约 633 KB 白做功）。
+         只有真的缺了这一章时才走动态注入 + 缺章登记。 */
+      if (window.STORY[m[i].id]) continue;
       var ok = await loadScript(m[i].file);
       if (!ok || !window.STORY[m[i].id]) missing.push(m[i].id);
     }
```

选的是问题稿里推荐的那条路：**保留 `index.html` 的 20 个静态标签**（双击即用、不依赖动态注入），
同时让 `boot()` 的缺章检测仍然有效 —— 只有在 `window.STORY[id]` 确实不存在时才去注入并登记缺失。
没有删 `index.html` 的标签，也没有改 `manifest.js`（冻结文件）。

## 未完成 / 降级

无降级。本条目只修「重复注入」这一件事：`index.html` 的静态标签与 `boot()` 的动态注入**两条入口都保留**，
只是第二条现在只在「静态那一次没成功」时才生效。

**给后续维护者的提醒**：如果以后有人把 `index.html` 里的静态标签删掉，`boot()` 会自动接管注入，
行为不变；但如果有人**只删标签、又不改这里**，就会恢复成「动态注入 20 章」—— 那时 `chapterScriptTags`
仍然是 20，探针不会报警。这是本条目没有覆盖的场景，登记在案。
