## 自检命令与输出

1）验收标准（第 2 条）：`rg -n "generated/ui" README.md` 必须命中"运行时不加载"的明确结论。

```powershell
rg -n "generated/ui" README.md
```

```
49:  ui/     16 个 UI 装饰 SVG（assets/generated/ui/）—— **构建期产物，运行时不加载**：
```

2）"运行时不加载"这句结论是**我实测出来的**，不是照抄原稿：

```powershell
rg -n "generated/ui" index.html css/style.css src art tools
```

```
tools\build-art.js:15: *   assets/generated/ui/{name}.svg
src\data\backgrounds.js:57:  /* UI 装饰 id 表（build-art 会为每个 key 生成 assets/generated/ui/<key>.svg） */
```

两条命中**都是注释**（一条在烘焙器里、一条在冻结的 id 表里），运行时代码 0 命中。

```powershell
(Select-String -Path css/style.css -Pattern 'url\(' -AllMatches).Count
```

```
0
```

`css/style.css` 里连一个 `url()` 都没有——界面确实全部是 CSS 直接画的，所以这 16 个 SVG
在运行时没有任何入口。

3）文件清单与体积（供验收组核对"16 个 / 85.5 KB"）：

```powershell
Get-ChildItem assets/generated/ui | Measure-Object -Property Length -Sum | Format-List Count, Sum
```

```
Count : 16
Sum   : 87600
```

（87,600 字节 = 85.5 KB，与原稿的「合计 85.5 KB」一致；最大的仍是 `paper_grain.svg` 75,564 字节。）
