## 改动

选了原稿明说的第二条路——**改上限的口径并写明理由与判据**，而不是硬压素材。

理由（原稿已论证、我复核后同意）：§4.4 原文的理由是「SVG 是文本，避免上万个碎多边形」，
针对的是**矢量面片数量**；而本仓库超标的实际原因是 `art/ui_00_crowd_stamps.js` 把群众贴图
以 base64 **内嵌位图**烘进 `bg`/`cg`。理由与现象对不上，且硬压的唯一手段是删掉画面里的
行军队伍（`bg_yudu_night` 是"火把排成一线"的夜渡、`bg_xiangjiang_day` 是渡江前的白昼江面，
队伍本身就是要拍的景）。

`docs/ART_DIRECTION.md` §4 第 4 条改为分档（并给出可复跑的自检命令）：

| 文件性质 | 上限 | 依据 |
|---|---|---|
| 纯矢量 SVG（无内嵌位图） | **400 KB** | 原条款，控制碎多边形数量 |
| 含内嵌位图素材的 SVG | **640 KB** | 贴图字节另算；实测最大 `cg/bg_xiangjiang_day.svg` = 583 KB |
| 立绘 PNG（AI 出图 600×900 RGBA） | **512 KB** | 自检实测最大 435 KB（`wu_laoliu_smile.png`） |

同时在该文件里写明：超档时才动手（减贴图段数 / 降每段像素），**不要为了数字去删画面里的
行军队伍**；并补了 §4 第 1 条与现实的偏差 → 记入 `docs/fixes/R1-BACKLOG.md` 第 2 条
（那一条不属于 R1-Q12，未顺手改）。

## 自检命令与输出

1）原稿的验收命令（只查 `bg/`+`cg/` 的 400 KB 硬线）。**素材一个字节没动**，所以它仍然报 8：

```powershell
node -e "const fs=require('fs'),p=require('path');const LIM=400*1024;let n=0;for(const d of ['bg','cg']){for(const f of fs.readdirSync(p.join('assets/generated',d)))if(fs.statSync(p.join('assets/generated',d,f)).size>LIM)n++;}console.log('超过 400KB 的文件数 = '+n);"
```

```
超过 400KB 的文件数 = 8
```

这是**预期**的：Q12 接受两条路（压素材 / 改口径），我走的是后者；下面第 2 条才是本次的判据。

2）改口径后的判据（写进了 `docs/ART_DIRECTION.md` §4.4，条文与命令一字不差）：

```powershell
node -e "const fs=require('fs'),p=require('path');let bad=0;for(const d of ['bg','cg','ui','chars']){for(const f of fs.readdirSync(p.join('assets/generated',d)).sort()){const fp=p.join('assets/generated',d,f);const s=fs.statSync(fp).size;let lim,why;if(/\.png$/.test(f)){lim=512*1024;why='立绘 PNG';}else if(/\.svg$/.test(f)){const emb=fs.readFileSync(fp,'utf8').indexOf('data:image')>=0;lim=(emb?640:400)*1024;why=emb?'含内嵌位图':'纯矢量';}else continue;if(s>lim){bad++;console.log('超档 '+(s/1024).toFixed(0)+' KB  assets/generated/'+d+'/'+f+'（'+why+'）');}}}console.log('超过本档上限的文件数 = '+bad);"
```

```
超过本档上限的文件数 = 0
```

3）分档用的两个关键实测值（写进条文里的数字，逐个复核过）：

```powershell
node -e "const fs=require('fs'),p=require('path');let mx=0,mxf='',mx2=0,mxf2='';for(const d of ['bg','cg']){for(const f of fs.readdirSync(p.join('assets/generated',d))){const fp=p.join('assets/generated',d,f);if(fs.readFileSync(fp,'utf8').indexOf('data:image')<0)continue;const s=fs.statSync(fp).size;if(s>mx){mx=s;mxf=d+'/'+f;}}}console.log('含内嵌位图的最大 SVG = '+(mx/1024).toFixed(0)+' KB ('+mxf+')');for(const f of fs.readdirSync('assets/generated/chars')){if(!/\.png$/.test(f))continue;const s=fs.statSync('assets/generated/chars/'+f).size;if(s>mx2){mx2=s;mxf2=f;}}console.log('最大的立绘 PNG = '+(mx2/1024).toFixed(0)+' KB ('+mxf2+')');"
```

```
含内嵌位图的最大 SVG = 583 KB (cg/bg_xiangjiang_day.svg)
最大的立绘 PNG = 435 KB (wu_laoliu_smile.png)
```
